# Contributing to Better Chaos Mod

Thanks for taking the time to contribute to Better Chaos Mod. Contributions of all kinds are welcome, including bug reports, feature ideas, code improvements, and documentation updates.

## How to contribute

### Reporting bugs

- Search existing issues before creating a new one.
- Use a clear title and include reproduction steps.
- Include relevant logs, screenshots, and game/environment details.
- Mention the Minecraft/Fabric version and mod version when possible.

### Suggesting features

Open an issue describing:

- the problem you want to solve
- the expected behavior
- any examples or context that may help

### Submitting code changes

1. Fork the repository.
2. Create a feature or fix branch.
3. Make your changes.
4. Build and test locally.
5. Open a pull request with a clear description of what changed and why.

## Local development

This project uses Gradle.

```bash
./gradlew build
```

If you are making gameplay or UI changes, it is recommended to validate them in a test environment before submitting a pull request.

## Pull request guidelines

- Keep changes focused and easy to review.
- Write clear commit messages.
- Include screenshots or short recordings when the change affects gameplay or UI.
- Update docs when behavior or setup changes.

## Code of conduct

Please keep discussions respectful, constructive, and focused on improving the project.

## Questions

If you are unsure where to start, open an issue and ask for guidance.
