# Security Policy

If you discover a security issue in Better Chaos Mod, please report it privately and responsibly.

## Reporting a vulnerability

Please use one of the following channels:

- GitHub Security Advisories (preferred when available)
- The project's support contact listed in the mod metadata

Please do not open a public issue for a security bug until it has been addressed.

## What to include

When reporting a vulnerability, include:

- a short description of the issue
- steps to reproduce it
- affected versions or environments
- any relevant logs or example payloads

## Response expectations

We aim to review and respond to reports as quickly as possible. If the issue is valid, we will work on a fix and coordinate disclosure in a manner that keeps users safe.
