# Better Chaos Mod
Inspired by the legendary GTA V Chaos Mod, Better Chaos Mod brings unpredictable, game-altering chaos directly into Minecraft!

## Chat Voting Platforms
- Twitch Integration
- Kick Integration

## Featured Events
- Deaf
- Drop Inventory
- Damage Items
- Force Sneak
- Inverted Controls
- ...
> List all events [here](https://matejtomecek.eu/projects/betterchaosmod/events).

## OBS Web Overlay
Built-in localhost web server at `localhost:9696`:
- `/poll` - Current poll voting view
- `/chat` - Filtered chat view stripping voting messages

Fully customizable via CSS, JS & WebSockets!
